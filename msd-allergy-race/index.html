MSD ALLERGY RACE Selected Unity Project Case Study

An interactive corporate gaming experience combining Unity 3D gameplay, Kinect motion controls, data-driven mechanics and real-world gamification.

01 / The Project

Racing driven by more than just player input.

The experience was designed as an engaging event activation where participants could interact with a racing game using body gestures. Employee and sales-performance metrics were incorporated into the experience to influence gameplay and personalise the journey.

02 / My Contribution
Unity 3D DevelopmentBuilt the interactive application and gameplay systems using Unity and C#.
Kinect IntegrationImplemented body and hand gesture interactions for navigation and vehicle control.
Gameplay SystemsDeveloped racing behaviour, vehicle controls, HUD elements and game-state logic.
Data-Driven ExperienceConnected performance-related values to gameplay presentation and player feedback.
Interactive UICreated gesture-driven menus, login, selection and instructional screens.
Event DeploymentPrepared the experience for repeatable real-world use during the interactive event.
03 / Gameplay
Real-time racing gameplay with HUD, performance indicators and track navigation.
04 / Interaction Design

Physical gestures became the interface.

The player used Kinect-based body movements and hand gestures to navigate menus and control the experience. The interface communicated each interaction clearly through large visual prompts, making it suitable for a public event environment.
